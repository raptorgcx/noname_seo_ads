# Т3 — Meta (FB/IG), главный платный канал. Чертёж кампании

Свежесть: 2026-07-16. **Статус: ЧЕРНОВИК — ждём доступ к Business portfolio
(блокер: 2FA draw.ro).** Search в Google закрыт политикой (см.
`t1-search-campaign.md`), весь платный бюджет — сюда.

## Почему Meta и что уже готово

- Кальянные НЕ входят в запрещённые категории Meta, но реклама не может
  ПРОДВИГАТЬ табак: в креативах — ни табачных слов, ни дыма/кальяна в кадре.
  Продаём то, что легально и что реально решает: атмосфера, терраса,
  PS5-комнаты, кухня/коктейли, лёгкая бронь.
- Готово: FB-страница (полный контроль владельца, категория «Cafenea cu
  narghilele», сайт /fb, адрес 2A, $$), IG noname.lounge привязан ✓,
  кнопка «Află mai multe» → /fb#rezerva.
- Блокер: своё Business portfolio владельца (упёрлось в 2FA draw.ro) →
  ad account **RON / Bucharest** (валюта и пояс необратимы) → карта.

## Пробел, который закрыть ДО запуска: Meta Pixel

На сайте его нет (стоят GA4 + Clarity + AW-тег). Без пикселя нет ни
конверсий, ни ретаргетинга, ни lookalike. План: создать пиксель в новом
портфолио → handoff в noname_site — добавить в analytics.js рядом с AW-тегом
(fbq init + track по нашим событиям booking_submit / wa_click / tel_click),
за consent-баннером как всё остальное. Полчаса работы, делаем сразу после
создания портфолио, параллельно модерации первой кампании.

## Структура запуска (минимальная, 1 кампания)

| Параметр | Значение |
|---|---|
| Цель | Traffic → лендинг /fb#rezerva (после накопления пикселя → Leads/Conversions на booking_submit) |
| Бюджет | 50 RON/день на старт (≈10 €), CBO выкл — бюджет на адсете |
| Гео | Бухарест + 15 км, «живущие здесь» (не путешественники) |
| Возраст | 20–45 |
| Аудитория | старт: broad (Advantage+ выкл, чистый гео+возраст). Интересы НЕ трогаем: табачных интересов у Meta нет, а «lounge/nightlife» сужают без пользы на малом бюджете |
| Плейсменты | Advantage+ (авто) — IG Feed/Reels/Stories + FB Feed; на 50 RON/день дробить вручную рано |
| Расписание | круглосуточно (алгоритм сам найдёт вечерние пики; ручное расписание требует lifetime-бюджет — не надо) |
| Язык объявлений | RO основной; RU — вторым адсетом ПОЗЖЕ, когда RO даст бенчмарк |
| UTM | ссылка уже /fb (медиум зашит в редирект) + `utm_content={{ad.name}}` для разбивки по креативам |

## Креативы (3 на старт, без табака в словах и кадре)

Форматы: 9:16 видео/фото (Reels/Stories — главный объём) + 1:1 для лент.
Материал — с телефона владельца, вечером при гостях (свет у заведения есть).

1. **«Терраса»** — вечерняя терраса, огни, столы. Текст: «Terasă de vară în
   Băneasa. Coctailuri, sushi, seri lungi. Rezervă în 30 de secunde.»
   CTA: Rezervă / Află mai multe → /fb#rezerva
2. **«PS5-комнаты»** — приватная комната, геймпад, экран. Текст: «Camere
   private cu PS5 — pentru serile cu prietenii. Deschis zilnic 13:00–01:00.»
3. **«Атмосфера/бар»** — бармен, коктейль крупно, интерьер. Текст: «Lounge
   premium la 5 minute de aeroport. Parcare proprie. Masa ta e liberă?»

Правило кадра: кальяны в кадр не берём вообще (даже фоном) — модерация Meta
смотрит изображение, не только текст. Стаканы/еда/люди/интерьер — ок.

## Правила чтения теста (те же, что были для Т1)

Метрика решения: стоимость (booking_submit + wa_click), порог ≤ 20–25%
среднего чека. Первые 3–4 дня не трогаем (обучение). До пикселя смотрим

вердикт по креативам (слабый меняем, не правим), через 14 — по каналу.
