## Почему фундамент уже готов (это важно)

Обычно рекламу нельзя запускать, потому что нечем мерить. У нас уже есть:
- GA4 с событиями `wa_click` / `tel_click` / `booking_submit` (+ consent mode) — конверсии
  для импорта в Ads готовы;
- метка источника из utm/gclid дописывается в WhatsApp-сообщение (`[ga]` и т.п.) —
  петля до реальной брони замыкается руками хостес;
- Syrve-дашборд (/dash/) — деньги по чекам, можно считать не только CPL, но и выручку.
