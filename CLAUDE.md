## Правила работы

1. **Коммит на каждое законченное действие, пуш сразу** (`origin main`) — владелец хочет всё
   в GitHub без задержки. Сообщения на английском: `тип: что сделано` (feat/fix/docs/chore).
   В начале сессии — `git pull` (main двигают и другие агенты).
2. Текущее состояние — в README.md этой репы (секция «Статус»), обновлять каждую рабочую
   сессию. Решения и их причины — фиксировать в затронутом доке со стампом даты.
3. **Деньги тратятся только с явного одобрения владельца.** Любой запуск/изменение бюджета
   кампании — сначала предложение с цифрами, потом его «да».
4. Доки — RU; всё клиентское (объявления, лендинги, ключевые слова) — RO/RU/EN как на сайте.
5. Красные линии SEO (уже зашиты в проект, не пересекать): никакой aggregateRating-разметки
   на цитируемых Google-рейтингах; текст чужих отзывов не републиковать; каталог — только
   страницы с ручным копирайтом (без тонких дорвеев).
