# HookahRadar — стратегия роста и монетизации

Свежесть: 2026-07-16. Статус: ИДЕИ, одобренных решений нет. Реализация —
через канал noname_parser (владелец: «в хукарадар не лезь, я это через
noname_parser общаюсь»); здесь только стратегия.

## Развилка, которая определяет всё

- **Путь А — сателлит NO NAME (текущий):** каталог на nonamelounge.ro,
  SEO-вес качает основной домен, NO NAME первым в списке. Монетизация
  вторична; валюта — трафик и позиции своего заведения.
- **Путь Б — самостоятельный продукт:** переезд на hookahradar.ro (домены
  куплены, сейчас 301). Только «нейтральной» площадке конкуренты понесут
  деньги — но nonamelounge.ro теряет SEO-вес каталога.

Решение: сидим на А, пока GSC не докажет спрос (первый срез 2026-07-18/20).
Строим то, что полезно на обоих путях.

## Чтобы заведения ХОТЕЛИ листинг

1. **Claim («Это ваше заведение?»)** — кнопка на каждой странице: поправить
   часы, соцсети, меню, СВОИ фото. Их контент = уникальный контент для нас
   (+ снимает лицензионный вопрос гугл-фото).
2. **Бейдж «4.9 на HookahRadar»** — эмбед со ссылкой → петля бэклинков →
   авторитет домена → листинг ценнее. Емейлы для аутрича уже в датасете
   (enrich_web).
3. **«Топ-10 кальянных Бухареста»** ежеквартально, по объективной формуле
   (рейтинг × отзывы) — попавшие репостят сами; формат для СМИ/телеграма.
4. **Города — главный рычаг:** опубликовано 28 (Бухарест), в датасете 241
   подтверждённая по Румынии (Клуж, Тимишоара, Констанца, Яссы…). Каждый
   город = пул брендовых запросов с нулевой конкуренцией. ×5–8 без нового кода.

## Все заведения или отбор? Ответ: этажи (решение владельца 2026-07-16 — «дай вердикт»)

**Полнота внизу, витрина сверху, мусор — никогда.**

- **Страницы — почти всем сидячим:** каждая ловит брендовый запрос
  «<название> + narghilea/отзывы»; заведение с 3.7 гуглят так же, как с 4.9.
  Нет страницы = запрос уходит Maps/ialoc. Честные тройки конкурентов — фон,
  на котором 4.9 NO NAME выигрывает.
- **Витрина (хаб, топ города) — только 4.0+**: обещание кураторства не
  размываем. Слабые живут на нижних этажах (секторные списки, «все заведения»).
- **Не берём никогда:** магазины/доставку (политика: только сидячие),
  заведения без данных (страница-пустышка = риск «scaled content»),
  рестораны (решение владельца от 2026-07-14, не пересматриваем).
- **Условие масштаба:** уникальный копирайт на каждую страницу (copy.yaml).
  200 страниц под копирку = фильтр scaled content на ВЕСЬ домен, включая
  основной сайт. Расширяемся партиями с текстами, не оптом.

## Монетизация (лестница)

1. **Платный профиль** €15–25/мес: галерея, описание, кнопка брони/WhatsApp,
   «Verificat». Бухарест: 5–10 плательщиков = мелочь; страна: 40–50 = €700–1000/мес.
2. **«Promovat»** — платное поднятие в списке. Без конфликта только на пути Б
   или в городах, где NO NAME нет (позиция №1 в Бухаресте не продаётся).
3. **Комиссия с брони** — потом, если появится поток. Большая стройка.
4. **Красные линии:** реклама табака/табачных брендов — запрещена законом в
   Румынии, не открываем; перепродажа данных — нельзя (ядро лицензировано
   у Google).

3. На 30–50 заведениях с трафиком: платные профили + решение развилки А/Б.
